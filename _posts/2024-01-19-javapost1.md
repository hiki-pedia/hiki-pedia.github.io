## 자뱌의 기본적인 개념

```java
public class HelloJava{
  public static void main(String[] args) {
    System.out.printIn("hello java");
  }
}
```

<blockquote>
    <dl>
      <dt>주의!</dt>
       <dd>Java는 대소문자를 구분한다.</dd>
    </dl>
</blockquote>

```java
public class HelloJava
```
<ul>
  <li>HelloJava는 클래스 이름이다.</li>
  <li>HelloJava.java라는 파일을 만들었다는 뜻.</li>
  <li>파일명과 클래스 이름이 같아야한다.</li>
  <li>{}을 사용하여 클래스의 시작과 끝을 나타낸다.</li>
</ul>

```java
public static void main(String[] args)
```
<ul>
  <li>main은 프로그램의 시작 메서드다.</li>
  <li>java는 main(String[] args) 메서드를 찾아서 프로그램을 시작한다.</li>
</ul>

```java
System.out.printIN("hello java");
```
<ul>
  <li>System.out.println(): 콘솔에 값을 출력한다.</li>
  <li>""사이에 원하는 문자열을 넣는다.</li>
  <li>단축키: sout</li>
</ul>

## 주석(comment)

주석으로 설명을 남기거나 코드 실행을 잠시 제외한다.

### 주석의 종류

<dl>
  <dt>한 줄 주석</dt>
</dl>
<ul>
  <li>// 기호로 시작한다. 이 기호 이후의 모든 텍스트는 주석으로 처리된다.</li>
</ul>
<dl>
  <dt>여러 줄 주석</dt>
</dl>
<ul>
  <li>/* 로 시작하고 */로 끝난다. 이 사이의 모든 텍스트는 주석으로 처리된다.</li>
</ul>

## 변수

```java
package variable;

public class Var1 {
    public static void main(String[] args) {
        System.out.println(10);
        System.out.println(10);
        System.out.println(10);
    }
}
```

### 패키지(package)
<ul>
  <li>파일을 구분하기 위한 폴더</li>
  <li>variable이라는 패키지를 만들었다면 첫 줄에 package variable;와 같은 패키지를 선언해주어야 한다.</li>
</ul>

상수를 여러 곳에 직접 쓰면 값을 바꿀 때 모두 수정해야 한다.

```java
package variable;

public class Var2 {
    public static void main(String[] args){
        int a;
        a = 10;
        System.out.println(a);
        System.out.println(a);
        System.out.println(a);
    }
}
```

변수를 쓰면 값을 한 곳에서 바꿀 수 있다.

### int a
정수를 보관할 수 있는 변수를 선언

```java
package variable;

public class Var3 {
    public static void main(String[] args){
        int a; // 변수 선언
        a = 10; // 변수 초기화: a(10)
        System.out.println(a); // 10 출력
        a = 50; // 변수 값 변경: a(10 -> 50)
        System.out.println(a) // 50 출력
} // 결과 적으로 10과 50이 출력된다.
```
대입하면 변수의 기존 값이 새 값으로 바뀐다.
지역 변수는 사용 전에 초기화해야 한다.

### 리터럴
코드에 직접 적은 `100`, `10.5` 같은 값을 리터럴(literal)이라 한다.

### 변수 타입 2
```java
package variable;

public class Var5 {
    public static void main(String[] args){
        // 정수
        byte b = 127; // -128 ~ 127
        short s = 32767; // -32767 ~ 32767
        int i = 2147483647 // -2147483648 ~ 2147483647

        // -9223293214389742 ~ 9223293214389741
        long l = 9223293214389741L;

        // 실수
        float f = 10.0f;
        double d = 10.0;
    }
}
```
자료형마다 메모리 크기와 표현 범위가 다르다.

#### 정수형
<ul>
  <li>byte : 1byte, 2<sup>8</sup></li>
  <li>short : 2byte, 2<sup>16</sup></li>
  <li>int : 4byte, 2<sup>32</sup></li>
  <li>long : 8byte. 2<sup>64</sup></li>
</ul>

#### 실수형
<ul>
  <li>float : 7자리 정밀도, 4byte, 2<sup>32</sup></li>
  <li>double : 15자리 정밀도, 8byte. 2<sup>64</sup></li>
</ul>

#### 기타
<ul>
  <li>boolean : true, false (1byte)</li>
  <li>char : 문자 하나 (2byte)</li>
  <li>String : 문자열 표현, 메모리 사용량은 동적으로 달라짐</li>
</ul>

#### 리터럴 타입 지정
<ul>
  <li>정수 리터럴의 기본 타입은 int다. long은 L을 붙인다.</li>
  <li>실수 리터럴의 기본 타입은 double이다. float는 f를 붙인다.</li>
</ul>
